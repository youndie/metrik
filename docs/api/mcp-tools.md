# mcp-tools — что metrik умеет рассказать агенту

Дашборд читает человек, а во время разбора инцидента данные нужны и агенту. HTML для этого не
годится: страницу нельзя вызвать как функцию. Поэтому у сервера есть MCP-эндпоинт.

Транспорт — `POST /mcp` (streamable http, stateless). Инструменты **только читают**: ни один не
меняет состояние, все помечены `readOnlyHint`.

Рядом стоит tracy с логами по MCP. Разделение простое: tracy отвечает на «что писал сервис»,
metrik — «когда стало медленно и насколько». Агент, у которого есть оба, может их сопоставить.

## Доступ

| переменная | смысл |
|---|---|
| `METRIK_MCP_TOKEN` | Bearer-токен. **Не задан — эндпоинта нет вовсе** |
| `METRIK_MCP_ALLOWED_HOSTS` | список хостов через запятую; пусто — проверка `Host` выключена |

Запрос без токена получает `401` с телом-JSON, а не страницу входа: клиент здесь машина, и
редирект на `/login` она прочитать не может.

Заголовки браузерного контура (`X-Auth-Request-*`) авторизацией **не считаются**. Прокси
принимает любую заявленную личность — для браузера за формой входа это нормально, для машинного
эндпоинта это дыра.

Маршрут `/mcp` идёт мимо oauth2-proxy, поэтому в чарте обход рендерится только вместе с токеном:
без него он появился бы без той аутентификации, которую собой заменяет.

## Инструменты

Окно (`from`, `to` — epoch millis) обязательно у всех, кто его принимает. Умолчание «за всё
время» читается как удобство, а ведёт себя как полный скан.

Сервис задаётся **именем**, а не числовым id: `metrik-server`, а не `7`. Опечатка в имени даёт
ошибку со списком известных сервисов — пустой ответ агент прочитал бы как «проблем нет».

| инструмент | аргументы | отдаёт |
|---|---|---|
| `list_services` | — | сервисы за последние 5 минут: rps, доля ошибок, p95, инстансы, последний пакет, горящие правила |
| `service_overview` | `service`, `from`, `to` | запросы, ошибки, доля ошибок, p50, p95, максимум |
| `slow_routes` | `service`, `from`, `to`, `limit` | маршруты **по убыванию p95** |
| `server_errors` | `service`, `from`, `to`, `limit` | только 5xx по маршрутам, по убыванию количества |
| `time_series` | `service`, `from`, `to`, `step` | ряд: rps, доля ошибок, p50, p95, максимум по шагам |
| `deploys` | `service`, `from`, `to` | версии в окне с моментом первого появления |
| `firing_alerts` | — | правила, горящие прямо сейчас, по всем сервисам |

`limit` по умолчанию 20, максимум 100.

## Что в описаниях инструментов и почему это важно

Описания — часть контракта, а не украшение. Три места, где агент без подсказки сделает
неправильный вывод:

* **`slow_routes` сортирует по p95, а не по частоте.** Самый частый маршрут обычно самый быстрый,
  и сортировка по количеству на вопрос «что тормозит» не отвечает. У HTTP-API сортировка другая —
  там таблица, которую человек смотрит глазами.
* **`server_errors` не показывает 4xx.** Это намеренно: 4xx — про клиента, и в вопросе «что у нас
  сломалось» они шум.
* **Заглушенное правило продолжает гореть** и остаётся в `firing_alerts`. Заглушение убирает
  уведомление, а не проблему; иначе «заглушил» означало бы «сделал вид, что всё хорошо».
* **`time_series` отдаёт не тот шаг, который попросили**, если попросили минутный за пределами
  ретенции: минутные окна живут ограниченное время, и сервер молча переходит на часовой. Что он
  отдал на самом деле — в поле `step`, и считать надо по нему.
* **`time_series` не присылает точку для окна, в котором данных не было.** Пауза приезжает более
  коротким рядом, а не рядом с дырой, поэтому считать «сколько минут сервис молчал» по длине списка
  нельзя — только по `at` соседних точек. Точка с `partial: true` — неполное окно: данных меньше,
  а не нагрузки, и складывать её с соседями нельзя.

Отдельно про `clockSkew` в `list_services`: `true` означает, что часы инстанса разъехались с
сервером. Цифры по нему — настоящие цифры, но время у них своё, и сопоставлять их с чужой
хронологией нельзя.

## Чего здесь нет

Записи. Заглушить правило, поменять порог или удалить сервис через MCP нельзя — это делается
руками в дашборде. Инструмент диагностики, умеющий менять состояние, однажды поменяет его
вместо диагностики.
